# Sprachregel

Die ausführliche interne Sprachregel und das gemeinsame Glossar werden im privaten Repository [`sovinityAI/.github-private`](https://github.com/sovinityAI/.github-private/blob/main/SPRACHE.md) gepflegt.

Öffentliche Produktkommunikation folgt ihrem jeweils freigegebenen Sprachkonzept. Beiträge und Pull Requests in diesem Repository werden grundsätzlich auf Deutsch geführt; technische Bezeichner, Code und unveränderliche Zitate dürfen in ihrer Originalsprache bleiben.
