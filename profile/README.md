# Sovinity

**Private AI for documents — with evidence, control, and data sovereignty.**

**Sovinity Docs** focuses on questions and verifiable answers from local documents for personal use, beginning with household documents.

- Ask questions across local documents and inspect the source passages
- OCR and semantic search for scanned and digital records
- Local processing on your computer

Sovinity Docs is under development. This profile does not announce a public launch.

[Website](https://sovinity.de/)
